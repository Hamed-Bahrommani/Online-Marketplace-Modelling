# Online Marketplace Modelling

A university project for the **Software Design Concepts** course.

## Project Overview

This repository contains the documentation, models, diagrams, and supporting materials developed throughout the project.

The project focuses on modelling an online marketplace system, following the requirements and deliverables defined by the course.
